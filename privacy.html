Chess Multiplayer Online: Privacy Policy

Last updated 16 October 2026 · Developer: Ajin Abhilash, Magdeburg, Germany

Chess Multiplayer Online is a free chess game for Android. This policy explains what information the app uses and why.

No account, no ads, no tracking

You do not need an account to use the app. The app shows no advertising and contains no analytics or tracking tools.

Offline games

Games against the computer and pass-and-play games run entirely on your device. Nothing is sent anywhere.

Online games

To play online with a friend, the app stores only what is needed for the game to work:

  • the player name you type (you can use any nickname),
  • the 6-character game code,
  • the list of moves and the game result.

This information is stored with our database provider, Supabase, on servers in Frankfurt, Germany, and is transmitted using encryption. It is used only to run the game and is never sold or shared with anyone else. Anyone who has a game's code can see that game's names and moves.

Chat messages are sent live between the two players in a game and are not stored.

Permissions

The app needs internet access for online games. It does not access your contacts, location, camera, microphone, photos or files.

Children

The app is suitable for all ages. It does not knowingly collect personal information from children beyond the nickname described above.

Deleting your data

To have an online game deleted, email the game code to the address below and it will be removed.

Changes

If this policy changes, the updated version will be published on this page with a new date.
